# 工作流程｜币安Alpha与Booster监控

## Alpha

公开空投列表 → 按合约/代币日期生成键 → 与本地状态比较 → 可选公开市场流通检查 → 新增/变更提醒 → 提前窗口提醒 → 稳定度检查与冷却 → 保存状态。

提醒通常有3次上限；临近开抢与稳定度提醒不共用此上限。接口异常必须与“没有新项目”区分；现有历史逻辑仍有混淆，不能据此自动交易。

## Booster

页面可访问性探测 → 分类公告列表 → 必要时读详情 → 关键词过滤或全部公告模式 → 首轮静默基线 → 按渠道记录发送进度 → 保存状态。失败渠道下次重试，成功渠道避免重复。

## 修改与协作

先读README、STATUS及仓库协作规则；单任务一个写入负责人，独立分支。先运行15项离线测试，再做经授权的只读网络验证。使用临时运行目录、关闭推送，绝不从生产复制认证/状态。更新状态、迁移摘要、中文文件索引及变更记录。

## 候选改进

优先补通知HTML安全转义、并发互斥、接口健康状态、失败重试与首次基线选项。该候选列表不是自动启用任务。
