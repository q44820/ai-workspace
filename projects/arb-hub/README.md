# Arb Hub｜公开市场套利聚合网页

来自线上项目的脱敏代码副本，与价差中位数网页basis-radar是独立项目。仅观察公开数据，不登录交易账户、不下单。

## 包含
- `app.py`：本地网页、导入和状态接口。
- `official.py`：公开行情适配、严格标的身份检查、资金费/价差展示。
- `runtime.py`：独立缓存、定时调度及失败退避。
- `public_proxy.py`：可选只读反向代理。
- `static/`：中文网页。旧生产快照、手动导入数据和缓存均不包含。

## 运行
Python 3.10+，仅标准库：
```bash
python3 test_hub.py
python3 app.py --bind 127.0.0.1 --port 8899
```
默认仅回环访问，运行会请求公开行情；需网络。`/api/state`为状态入口。运行目录默认`runtime/`，可由`ARB_HUB_RUNTIME`指定。默认禁止导入，不开启公网端口。

## 限制
行情不代表可成交价；缺少周期/标的/计价身份时不得自行补齐。部分外部站点仅外链，地域限制不绕过。公开副本不带历史机会数据，初始列表可能为空。离线测试不代表当前全源可用、机会有盈利或线上已更新。
