# ANTH Bot｜价差机器人代码归档（离线专用）

保存原Entropy/Hyperliquid HIP-3与Lighter之间的ANTH价差策略、状态机和控制台代码，便于AI研究与交接。属于历史衍生品策略归档，不是现货项目，也不是当前交易建议或实盘授权。

## 安全修改
- `bot.py`直接启动即拒绝；`main()`及真实交易客户端初始化同样明确拒绝。
- 强制`DRY_RUN=True`，不读取`.env`，屏蔽账户及私钥环境字段；不加载交易SDK。
- 外部状态推送、公开账户状态页面关闭；默认数据只写本地独立`runtime/`。
- 使用通用离线参数；不保留生产账户参数和初始资金。
- 历史真实成交与账户校验脚本整份排除；`simtest.py`是可重复的合成场景，不是历史收益证明。

## 执行安全修复
- 每个开仓腿必须同时满足订单终态、足额成交和实际持仓匹配，才允许提交下一腿。
- 首腿拒单、部分成交、结果未知或确认等待结束仍未知，中止后续开腿；未知结果禁止重发，也不当成拒单。
- Lighter `sendTx` 返回 code 200 只表示接受，日志里的 `submission outcome unconfirmed` 不是官方拒单，也不能当成成交。订单终态只来自官方订单查询；`confirmSec` 仍只是开仓信号窗口，不作为这笔等待的超时。
- 接受后的终态最多只读等待约 6 秒。等待内官方确认足额成交才继续。超时仍未知则停止新开仓并持续只读对账：不重发、不平未知腿、不把 intent 自己写成 filled。单边或未确认敞口会明确告警并保持停止，未知不会自动恢复。之后若官方终态和仓位证明是完整对冲，只恢复这笔持仓的管理，不自动切回 live，也不新开仓。
- 第二腿前重新校验盘口新鲜度与所需深度；未完整开仓状态在重启后仍先只读对账，再决定能否新开。
- 正常回归平仓遇到订单回执延迟时保持原策略模式，只读核对、不重发、不新开仓；双边订单终态与实际仓位都确认后进入原冷却时间。成交明细暂缺时不把估算记成实盘收益，也不阻断已确认的归零。手动停止以及风控失败后的停止不自动解除。
- 残腿仅按实际数量减仓；风控失败停机不会因归零自动恢复。减仓不因缺少全量盘口深度而被新开仓深度门槛阻断。
- 首腿 Hyperliquid 即时成交否则撤销（IOC）明确零成交时，只有订单终态及双边仓位均确认归零、且没有发出第二腿才跳过本轮信号。原冷却后重新等待新信号，不重发同一订单、不记录虚假成交；仓位或订单待核对时不新开仓。保证金拒单与残腿仍走原有风控。
- `test_execution_safety.py`含33项合成故障及正常执行回归；模拟订单、临时状态且网络被阻断。其内部临时覆盖`DRY_RUN`仅用于测试状态机分支，不移除归档启动与签名阻断。
- 开仓执行、失败处理和对账函数与私有维护版本保持一致；账户、运行参数和实盘启动能力仍不公开。
- 已有更晚同所订单的历史终态，不再按当前净持仓改成 `terminal_wait` 或 `unknown`，也不擦掉已保存的官方证据。没有官方来源的最新本地 terminal，官方查询为空时仍降为 unknown。完整开平后该侧已空、且有更早同数量终态的平仓，查询窗口过期时保持 terminal。发单前因旧单退出不写成已提交退出，也不追加 intent。
- `test_history_reconcile.py` 用上述时序做回归，并覆盖两所合计亏损上限：默认 5U，非法金额拒绝，重启和改金额不重置基线，触发后仍可减仓，两个开仓门都不能绕过。这不是亏损硬封顶。公开 DRY_RUN 模拟没有官方权益，不启用这道门。
- 受污染现网状态的恢复步骤见 `RECOVERY_历史订单恢复方案.md`。该文件不授权在服务器上执行。

## 刷交易量模拟工具（与套利实盘独立）
- `paper.html`、`paper_engine.js`、`paper_app.js`、`paper.css` 为无签名能力的刷交易量模拟工具，复现 maker成交推断→延迟对冲→退出；不是实盘授权。
- 仅读取 Hyperliquid io:ANTH 公共盘口/逐笔与 Lighter 主站市场193盘口，不依赖可能过期的原网站缓存。不读取账户、密钥或原机器人配置。
- maker成交基于公共逐笔和队列模型推断，部分成交仅对冲推断数量，余单撤销；不能证明真实订单可成交。断流、深度不足保留风险，不伪造补腿。
- 默认单腿100U、IO maker 1bp、IO应急taker 3bp、LT taker 2.8bp、额外滑点1bp、观察成交后500ms对冲为实验假设；费率并未按账户核实。收益未含资金费、清算及平台成本，不计算积分。
- 页面只保留交易量模式，无套利切换、试验开仓、套利盈利参数或策略收益卡片。直接访问默认交易量模式、保持暂停；旧版历史与仓位保留，非交易量旧仓未结算时禁止新开轮次。共享引擎旧分支仅为兼容存档和既有回归保留。
- 原套利实盘看板和模拟页已迁日本服务器，从整合网站已鉴权入口进入；旧Vercel状态接口退役，不再读写Blob。交易算法、进程、配置与启停不作修改。
- 网页仅在浏览器打开时运行；后台脚本与浏览器localStorage是独立存档，网页为0不代表后台模拟为0。刷新暂停，不回放离线成交。
- 本地预览：在此目录运行 `python3 -m http.server 8913 --bind 127.0.0.1` 后打开 `http://127.0.0.1:8913/paper.html`；模拟状态仅存本浏览器。
- 回归：`node test_paper_engine.cjs`、`node test_paper_ui.cjs` 与 `node test_volume_profit.cjs`。合成fixture只在离线测试中使用，不能作为业绩展示。

## 当前默认：周转优先v2（试验，非原推复刻）
- 依据上一轮真实网页6小时表现改写：盘口顶层被动入场，按同盘口立即退出成本上限20bp筛选，不依赖2小时价差中位数回归。60秒真实健康预热、至少10样本，断采15秒重新预热。缩短预热是方案变化，不冒充原框架验证。
- 全天开仓与退出规则一致：优先满足扣费净收益目标；持仓60秒后允许12bp预估净亏限价maker退出，最长10分钟后尝试吃单退出。最短持仓0、原10秒冷却；30bp止损、5U总亏损预算、10000U目标、费率、500ms对冲和队列系数2均不变。限价和预算不是亏损硬封顶。
- 有效报价不再30秒机械撤单；目标差至少2个报价步长、至少驻留15秒才改价，退出单只向更积极方向改价。仍先处理已有逐笔，再决定是否撤单，不能删除不利推断成交。只有公共逐笔消耗队列才记maker成交，未成交挂单不计量。
- 记录每次实际推断入场采样的双边盘口和相同数量四腿吃单立即开平成本，按已结算比例分摊基准；独立累计v2策略/基准IO成交量与净收益，不混旧仓。该对照是同入场盘口静态成本估计，并非独立成交策略或可达吞吐量证明。
- 页面增加每小时IO成交量、每万U策略磨损与对照估计。均速是含暂停、预热的墙钟均速。旧0/1模型仓位继续旧退出规则，空仓后本机备份并升级，费率、预算、累计量、历史及旧仓不删除；旧框架回归继续保留。
- 默认参数和收益均未验证，不承诺更快、更低磨损或盈利。要用日本线上原网页真实行情跑6小时后验收，失败/风控停止不自动放宽预算重启。仅模拟，无钱包、签名、真实订单或积分。
- 新增离线回归：`node test_turnover_volume.cjs`；合成数据只验证状态机和费用计算，不是收益证据。

## 历史v1框架（仅旧仓兼容，不是新版默认）
- 目标是以刷交易量为核心，争取扣费后盈利，同时控制成本和亏损。本版本实际修正入退场代码，不再仅修改文案。
- 页面专注交易量和亏损评估，沿用maker推断成交→延迟对冲执行链，不读取凭据、不连接交易端点，不产生真实成交量或积分。
- 依据 [Captain原推](https://x.com/mycndota/status/2121412853362282885) 与 [30分钟退出复盘](https://x.com/mycndota/status/2120470815624085581)：2小时中位数锚定maker挂单，成交后LT反向对冲，工作日夜盘持仓30分钟后跟随中位数退出，允许小亏、不死等回本。作者Arcus/SPY与本页IO/ANTH不同，原推不是完整源码，本实现是标明假设的适配，不是逐行复刻。
- 按正常IO maker开平、LT taker开平路径反推被动挂单价格，不再要求当前盘口先出现+6bp净优势；LT深度、盘口和不利滑点、四腿费照常计入。IO应急吃单成本另列风控，不当作正常每轮必然成本。预估仍假设价差回中位数且LT中价不变，不是预测或收益保证。
- 默认报价最低净优势0bp+毒流余量1.5bp，余量是未验证的实验参数；账户费率未核实，不能照搬作者零手续费。成本上限20bp、止损30bp、累计目标10000U、亏损预算5U不变；最短30秒、最长8小时、冷却10秒、预热真实2小时且至少60个样本。8小时上限是附加风控，与作者早期8小时版本一致，不保证适用于ANTH。资金费未知。
- 工作日夜盘满30分钟跟随当前中位数挂maker退出，不强求每轮盈利；之前/周末按入场锚与扣费回本价挂单。撤改退出目标后重新排队。风控优先，止损、超时和预算退出可亏损；不保证硬封顶。原推建议夜盘，但具体北京时间21:00至次日05:00窗口是本工具公开适配，非已核验ANTH加成规则；默认限该窗口或周末新开仓，允许显式设为0进行全天试验，仓位风控始终执行。
- 页面显示预热剩余分钟、执行阶段、挂单U价/队列/单龄；默认必须真实采集2小时，不补造历史。不保证每小时成交，作者也仅自报72小时8轮。旧存档缺少模型标记保持旧模型，有旧仓/待对冲腿不迁移，空仓时本机备份旧参数并切新框架，保留费率/预算/历史/累计量/样本。
- 未成交挂单每次采样重新检查成本与风险，失效撤单；取消前已经发生的公共逐笔推断成交仍保留并对冲，不用后来盘口把不利成交删掉。两腿延迟对冲后结果可能偏离预估。
- IO与Lighter实际推断成交额逐腿累计，未成交挂单不记量，部分成交仅计实际推断量；已平部分费用和净收益比例分摊。累计量不因只展示最近500笔而截断。
- 每万U磨损以已结算对应IO开平成交额为分母；两所合计另列，不冒充任一平台认可量。未平仓不计已实现收益。
- 达目标仅退出不再开仓；亏损预算包含可估值浮亏并尝试应急吃单退出，深度不足保留风险，预算不保证亏损硬封顶。资金费未知、不计积分，实盘资格和排队成交不保证。
- 有挂单/敞口不能改参数；刷新保留记录与参数但暂停，待对冲腿中断仍冻结。真实浏览器验证不强行制造成交。
