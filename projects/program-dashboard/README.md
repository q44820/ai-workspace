# Program Dashboard｜程序总览看板

仅查看GitHub已收录的项目，不列未上传的旧任务、代理或系统服务。每个卡片保留功能、用途与代码链接；Alpha/Booster分别展示，LP按实际脚本拆成BNCB/BNB区间监控、币价区间监控、仓位核对与同步，不把一个项目下的独立程序藏在总卡片内。纯本地Python脚本采集，不调用大模型，不展示账户或资产，不提供操作按钮。

## 已有功能
- 已确认可访问的网页在程序名称上显示可点击链接和 ↗，新标签页打开；未部署或入口未核实则保持普通名称。实际链接保存在服务器私密 `runtime/web_links.json`，不写入GitHub；链接不携带密码或认证信息。
- 搜索、状态/位置筛选、手机布局；没有未上传GitHub的旧任务列表。
- 目录测试核对全部GitHub项目一一覆盖，禁止旧同步快照重新带入无关任务。
- 状态区分运行/定时启用/停止/异常/手动归档/未知，不把“定时等待”当停止。
- 日本服务约12秒缓存，页面30秒刷新；本机每5分钟上传白名单字段，超过15分钟标为过期。
- 带随机访问码的私密链接；无访问码不返回清单。禁写接口，no-store/no-referrer/CSP，不记请求路径日志。

## 测试
Python 3.10+标准库：
```bash
python3 test_dashboard.py
node --check static/app.js
```
`catalog.json`只含可公开的功能目录。`collect_local.py`只读系统状态，不执行任务，不上传提示词、原始错误、命令、日志、账户和配置。

## 运行与部署
`server.py`默认回环端口8902；需在私密runtime中提供`access.sha256`，内容为随机访问码的SHA256。真实访问码、URL、主机、SSH设置、服务配置和实时快照不放Git。

生产新建独立systemd看板/隧道，已启用自启；本机新建独立5分钟同步LaunchAgent。部署只影响新增组件，既有服务未修改。看板访问码是能力凭据，持有完整链接可读清单；请勿转发。不具备账号登录、MFA或细粒度权限。

### BNCB/BNB 私有网页

从总览的「BNCB/BNB LP区间监控」标题打开日本服务器上的只读网页版。首页由 `bncb_fast.py` 显示服务端上次同区块核实的两轮连续核算（累计投入、滚入代币、已领回款、当前未领费及 Gas），不等浏览器扫描链。快照过期时后台只读更新；仓位或钱包发交易次数发生变化时提示复核，不外推结果。账本、快照均留在私有目录。原单轮详细网页保留于 `?detail=1`，来自服务端私有文件 `private-pages/bncb-lp.html`，不通过 Vercel 转发。含钱包配置的文件不收录在 Git。页面在浏览器中读取公共链上节点，历史记录保存在浏览器；更换网站时应在旧站导出、在新站导入。此入口不迁移或重启本机的区间提醒脚本。
