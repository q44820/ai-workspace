# ANTH Bot｜价差机器人代码归档（离线专用）

保存原Entropy/Hyperliquid HIP-3与Lighter之间的ANTH价差策略、状态机和控制台代码，便于AI研究与交接。属于历史衍生品策略归档，不是现货项目，也不是当前交易建议或实盘授权。

## 安全修改
- `bot.py`直接启动即拒绝；`main()`及真实交易客户端初始化同样明确拒绝。
- 强制`DRY_RUN=True`，不读取`.env`，屏蔽账户及私钥环境字段；不加载交易SDK。
- 外部状态推送、公开账户状态页面关闭；默认数据只写本地独立`runtime/`。
- 使用通用离线参数；不保留生产账户参数和初始资金。
- 历史真实成交与账户校验脚本整份排除；`simtest.py`是可重复的合成场景，不是历史收益证明。

## 执行安全修复
- 每个开仓腿必须同时满足订单终态、足额成交和实际持仓匹配，才允许提交下一腿。
- 首腿拒单、部分成交、结果未知或超时，中止后续开腿；未知结果禁止重发。
- 第二腿前重新校验盘口新鲜度与所需深度；未完整开仓状态在重启后仍按恢复流程处理。
- 残腿仅按实际数量减仓；风控失败停机不会因归零自动恢复。减仓不因缺少全量盘口深度而被新开仓深度门槛阻断。
- `test_execution_safety.py`含25项合成故障及正常执行回归；模拟订单、临时状态且网络被阻断。其内部临时覆盖`DRY_RUN`仅用于测试状态机分支，不移除归档启动与签名阻断。
- 开仓执行、失败处理和对账函数与私有维护版本保持一致；账户、运行参数和实盘启动能力仍不公开。

`control.html`仅作界面代码参考，公开副本不提供可运行控制服务。未经新的明确交易授权，不得移除拦截、恢复实盘、迁入真实配置或操作线上机器人。

## 刷交易量模拟工具（与套利实盘独立）
- `paper.html`、`paper_engine.js`、`paper_app.js`、`paper.css` 为无签名能力的刷交易量模拟工具，复现 maker成交推断→延迟对冲→退出；不是实盘授权。
- 仅读取 Hyperliquid io:ANTH 公共盘口/逐笔与 Lighter 主站市场193盘口，不依赖可能过期的原网站缓存。不读取账户、密钥或原机器人配置。
- maker成交基于公共逐笔和队列模型推断，部分成交仅对冲推断数量，余单撤销；不能证明真实订单可成交。断流、深度不足保留风险，不伪造补腿。
- 默认单腿100U、IO maker 1bp、IO应急taker 3bp、LT taker 2.8bp、额外滑点1bp、观察成交后500ms对冲为实验假设；费率并未按账户核实。收益未含资金费、清算及平台成本，不计算积分。
- 页面只保留交易量模式，无套利切换、试验开仓、套利盈利参数或策略收益卡片。直接访问默认交易量模式、保持暂停；旧版历史与仓位保留，非交易量旧仓未结算时禁止新开轮次。共享引擎旧分支仅为兼容存档和既有回归保留。
- 原套利实盘看板仍位于 `https://anth-live.vercel.app/`，其交易算法、进程、配置与启停不作修改。该站主页面和整合网站均提供独立刷交易量工具入口；整合网站的 `anth-paper/` 仍受原访问权限保护。
- 网页仅在浏览器打开时运行；后台脚本与浏览器localStorage是独立存档，网页为0不代表后台模拟为0。刷新暂停，不回放离线成交。
- 本地预览：在此目录运行 `python3 -m http.server 8913 --bind 127.0.0.1` 后打开 `http://127.0.0.1:8913/paper.html`；模拟状态仅存本浏览器。
- 回归：`node test_paper_engine.cjs` 与 `node test_paper_ui.cjs`。合成fixture只在离线测试中使用，不能作为业绩展示。

## 刷交易量版本（纯模拟）
- 目标是以刷交易量为核心，争取扣费后盈利，同时控制成本和亏损；并非“不要求盈利”。本次纠正文案，不改变入退场参数或盈利门槛。
- 页面专注交易量和亏损评估，沿用maker推断成交→延迟对冲执行链，不读取凭据、不连接交易端点，不产生真实成交量或积分。
- 独立设置入场偏离、预热/样本数、估计往返成本上限、退出可接受净亏损、最短/最长持仓、退出冷却、IO累计开平成交额目标及亏损预算；争取盈利但不承诺结果。单腿金额、费率、滑点、延迟和排队模型共用。
- 默认目标10000U、亏损预算5U、往返成本上限20bp、退出可接受净亏损12bp、最短30秒/最长30分钟、冷却10秒、预热60秒且10个真实样本。这些仅是实验配置，不是盈利或真实费率承诺。
- IO与Lighter实际推断成交额逐腿累计，未成交挂单不记量，部分成交仅计实际推断量；已平部分费用和净收益比例分摊。累计量不因只展示最近500笔而截断。
- 每万U磨损以已结算对应IO开平成交额为分母；两所合计另列，不冒充任一平台认可量。未平仓不计已实现收益。
- 达目标仅退出不再开仓；亏损预算包含可估值浮亏并尝试应急吃单退出，深度不足保留风险，预算不保证亏损硬封顶。资金费未知、不计积分，实盘资格和排队成交不保证。
- 有挂单/敞口不能改参数；刷新保留记录与参数但暂停，待对冲腿中断仍冻结。真实浏览器验证不强行制造成交。
