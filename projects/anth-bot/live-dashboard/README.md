# ANTH 套利实盘只读看板

- `index.html` 为 `https://anth-live.vercel.app/` 主页面源码；套利看板与刷交易量模拟工具分开。主页面保留前往刷交易量工具的按钮，不再提供“套利模拟版本”入口。
- `api/status.js`、`api/ingest.js`、`vercel.json` 为既有看板服务的脱敏源码。本次保持两个API逐字节不变，不改变机器人算法、进程或启停。
- 凭据和存储连接只由Vercel项目私密环境变量提供；仓库不含项目本地连接文件、Token、访问码、账户配置或环境变量值。
- 部署时将本目录内容作为根目录，并将上级的 `paper.html`、`paper_app.js`、`paper_engine.js`、`paper.css` 放入根目录 `anth-paper/`。通过已授权的Vercel账号部署到既有 `anth-live` 项目；不要在其他项目中复用私密环境变量。
- 本仓库只是只读看板与模拟源码归档，不包含开启机器人实盘交易的授权。页面显示机器人推送快照，不保证实时行情；新套利代码的交易逻辑更新仍需独立测试和明确授权边界。
